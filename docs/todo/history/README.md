# docs/todo/history/ — 作業履歴の索引

**何をやったか・なぜそうしたか・どこで詰まったか**をセッション単位で残す。時系列（古いものが上）。

| ファイル | 期間 |
| --- | --- |
| （まだ無い） | 最初のセッションで `YYYY-MM.md`（量が増えたら `YYYY-MM-w1.md` のように週単位）を作り、この表へ 1 行足す |

## 書き方

- 見出しは `## YYYY-MM-DD <やったことの要約>`。**新しい記録はファイルの末尾へ足す。**
- 記号を避けた見出しにする（GitHub のアンカーが素直に決まるため）。
- 各ファイルの冒頭に、その中の節の目次を置く。
- 判断の理由・不採用にした案・詰まった原因まで書く。結果だけの記録は次に読む人の役に立たない。
