## 2026-08-31 画面遷移図とER図のSVGを生成し、レビュー指摘を修正

- 前回のセッションではローカルのDocker Desktopが未起動でSVG変換ができなかったため、Docker起動後にユーザーへ一度SVGを共有した。
- ユーザーから2点の指摘を受けた: (1) `画面遷移図.01.mmd`のノードラベルに`\n`をそのまま書いていたため改行が効かず「ToDo一覧画面\n未完了/完了タブ」のように文字列がそのまま表示されていた、(2) iOS Safariかつ未インストール時の案内表示が「ログイン画面」からの遷移としてのみ描かれており、未所属・初回ログインで「家族グループ作成・参加画面」へ向かうユーザーに対する考慮が図から読み取れなかった。
- (1)への対応: mermaidのflowchartノードラベルは`\n`では改行できず`<br/>`が必要なため、該当ノードを`todo_list["ToDo一覧画面<br/>未完了/完了タブ"]`のようにダブルクォート＋`<br/>`表記へ修正した。
- (2)への対応: `iOSインストール案内`を「ログイン画面」からの片方向の一発表示ではなく、「家族グループ作成・参加画面」「ToDo一覧画面」の両方から出入りするオーバーレイとして描き直した（`group_entry -.-> ios_guide -.-> group_entry`、`todo_list -.-> ios_guide -.-> todo_list`）。あわせて`画面遷移図.md`の「遷移の要点」も、未所属・所属済みいずれの場合も同条件で表示し閉じた後は表示元の画面に留まる旨に書き直した。
- `MSYS_NO_PATHCONV=1`無しでは Git Bash から Docker のマウントパスが壊れて`docs/diagrams.md`の注意書きどおり`-i`のファイルが見つからないエラーになったため、`MSYS_NO_PATHCONV=1 docker run --rm -v "$(pwd)":/data minlag/mermaid-cli:11.12.0 ...`の形で実行して解決した。
- `画面遷移図.01.svg`・`family-todo/01_データベース.01.svg`を再生成してコミット対象に含めた。
