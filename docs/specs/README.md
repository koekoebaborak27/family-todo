# docs/specs/ — 設計ドキュメント

**設計・仕様の決定はここが正本。** `docs/todo/TODO.md` には残タスクだけを書き、仕様は書かない。

| ディレクトリ | 何を置くか |
|---|---|
| [`01_requirements/`](01_requirements/README.md) | 要件定義書（機能ごと） |
| [`02_basic-design/`](02_basic-design/README.md) | 基本設計書（画面・API・DB。機能ごとに分割） |
| [`03_detail-design/`](03_detail-design/README.md) | 詳細設計書（必要な機能のみ） |
| [`99_infra/`](99_infra/README.md) | インフラ構築手順（手順ごとに分割） |

## 書き方の約束

- **1 機能 1 ディレクトリ**。ディレクトリごとに `README.md`（索引）を置き、そこから各ファイルへリンクする。
- ファイル名は `<2桁の番号>_<内容>.md`。番号は画面・機能の並び順に合わせ、間を空けて採番する（後から挟めるように）。
- **作成経緯や検討の過程を書かない。** 決まったことだけを「〜すること」の形で書く。経緯は `docs/todo/history/` に残す。
- 1 ファイルが 20KB を超えたら分割する。エージェントに全文を読ませないためのしきい値。
- 図は `docs/diagrams.md` の手順に従い、`.mmd` + `.svg` で管理する。
