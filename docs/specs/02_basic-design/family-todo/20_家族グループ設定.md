# 家族グループ設定画面

共通仕様（用語・権限・API共通規約）は [`00_family-todo共通.md`](00_family-todo共通.md) を参照。

## 1. 画面の目的

所属している家族グループの状態を確認・管理する。メンバーの確認、非登録メンバー（名前だけの担当者）の追加・削除、招待リンクの発行、グループからの退出、グループの削除をこの画面で行う。

## 2. 画面へのアクセス条件・初期表示

- ログイン済みかつ家族グループに所属しているユーザーのみが対象。
- ToDo一覧画面のヘッダーメニューから開く。
- 画面表示時に `GET /families/me`・`GET /families/me/members`・`GET /families/me/unregistered-members` を呼ぶ。

## 3. 表示項目

上から次の順に並べる。

### 3.1 グループ情報

| 項目 | 内容 |
| --- | --- |
| グループ名 | `families.name` |
| 作成日 | 例: `2026/8/30 に作成` |

- グループ名の変更はMVPでは行えない（要件に変更機能が無いため）。表示のみとする。

### 3.2 メンバー（登録ユーザー）

| 項目 | 内容 |
| --- | --- |
| 見出し | `家族メンバー (3人)` |
| 各行 | 表示名。自分の行には `(あなた)`、グループ作成者の行には `(作成者)` を付ける |

- 他のメンバーをグループから外す操作はMVPでは設けない（権限が全員一律のため、追い出し合いが起きないようにする）。

### 3.3 非登録メンバー

| 項目 | 内容 |
| --- | --- |
| 見出し | `非登録メンバー (2人)` |
| 説明文 | `アプリにログインしない人（お子さんなど）を、担当者として選べるように登録します。` |
| 各行 | 名前と「削除」ボタン |
| 追加欄 | 名前の入力欄と「追加」ボタン |
| 0件のとき | `非登録メンバーはまだ登録されていません。` |

### 3.4 招待

| 項目 | 内容 |
| --- | --- |
| 見出し | `家族を招待する` |
| 招待コード | 半角英数字8桁。例: `A3F9K2QP` |
| 有効期限 | 例: `2026/9/6 まで有効` 。期限を過ぎている場合は `有効期限が切れています` と表示する |
| 招待リンク | 例: `https://<アプリのURL>/join?code=A3F9K2QP` |
| 「リンクをコピー」ボタン | 招待リンクを端末のクリップボードにコピーする |
| 「招待コードを再発行」ボタン | 新しいコードを発行する |

### 3.5 グループから抜ける

| 項目 | 内容 |
| --- | --- |
| 「グループを退出する」ボタン | 全メンバーに表示する |
| 「グループを削除する」ボタン | グループ作成者にのみ表示する。破壊的な操作として他と区別できる見た目にする |

## 4. 入力チェック

| 項目 | チェック内容 | エラー文言 |
| --- | --- | --- |
| 非登録メンバーの名前 | 未入力（空白のみも含む）でないこと | `名前を入力してください。` |
| 非登録メンバーの名前 | 20文字以内 | `名前は20文字以内で入力してください。` |
| 非登録メンバーの名前 | 同じグループ内で重複していないこと（サーバー側で判定し `409` を返す） | `同じ名前の非登録メンバーがすでに登録されています。` |

- 重複の確認はサーバー側の応答で行う。画面側では入力済みの一覧と突き合わせて、送信前にも同じ文言を表示してよい。

## 5. 操作と遷移先

| 操作 | 動作 | 遷移先 |
| --- | --- | --- |
| 非登録メンバーの「追加」 | `POST /families/me/unregistered-members` を呼ぶ。成功したら入力欄を空にし、一覧に追加してトーストで `非登録メンバーを追加しました。` を表示する | 同画面 |
| 非登録メンバーの「削除」 | 確認ダイアログ（`AlertDialog`）で `{名前} を削除します。この人が担当者になっているToDoからも外れます。削除しますか？` を表示する。承諾したら `DELETE /families/me/unregistered-members/:id` を呼び、トーストで `非登録メンバーを削除しました。` を表示する | 同画面 |
| 「リンクをコピー」 | クリップボードにコピーし、トーストで `招待リンクをコピーしました。` を表示する | 同画面 |
| 「招待コードを再発行」 | 確認ダイアログ（`AlertDialog`）で `新しい招待コードを発行します。今のリンクは使えなくなります。再発行しますか？` を表示する。承諾したら `POST /families/me/invite` を呼び、表示を新しいコードに差し替えてトーストで `招待コードを再発行しました。` を表示する | 同画面 |
| 「グループを退出する」 | 確認ダイアログ（`AlertDialog`）を表示する（文言は下記）。承諾したら `POST /families/me/leave` を呼ぶ | 家族グループ作成・参加画面 |
| 「グループを削除する」 | 確認ダイアログ（`AlertDialog`）で `家族グループ「{グループ名}」を削除します。ToDo・コメント・非登録メンバーがすべて消え、元に戻せません。削除しますか？` を表示する。承諾したら `DELETE /families/me` を呼ぶ | 家族グループ作成・参加画面 |
| 戻る | | ToDo一覧画面 |

退出の確認ダイアログの文言は、自分が最後の1人かどうかで変える。

| 状況 | 文言 |
| --- | --- |
| 他にもメンバーがいる | `家族グループ「{グループ名}」から退出します。あなたが担当者になっているToDoからは外れます。退出しますか？` |
| 自分が最後の1人 | `あなたが最後のメンバーです。退出すると家族グループ「{グループ名}」は削除され、ToDo・コメント・非登録メンバーもすべて消えます。退出しますか？` |

- 退出後は移動先の家族グループ作成・参加画面でトーストで `家族グループから退出しました。` を表示する。
- 削除後は同様に `家族グループを削除しました。` を表示する。

## 6. 権限による差

| 操作 | 誰ができるか |
| --- | --- |
| メンバー・非登録メンバーの閲覧 | グループの全メンバー |
| 非登録メンバーの追加・削除 | グループの全メンバー |
| 招待リンクの表示・コピー・再発行 | グループの全メンバー |
| グループの退出 | グループの全メンバー（自分自身のみ） |
| グループの削除 | グループの作成者のみ。作成者以外には「グループを削除する」ボタンを表示しない |

## 7. エラー時の表示文言

| 状況 | 表示文言 | 表示場所 |
| --- | --- | --- |
| 非登録メンバーの名前が重複（`409`） | `同じ名前の非登録メンバーがすでに登録されています。` | 名前の入力欄の下 |
| 非登録メンバーの追加に失敗（`500` 系） | `非登録メンバーの追加に失敗しました。もう一度お試しください。` | トースト |
| 非登録メンバーの削除に失敗 | `非登録メンバーの削除に失敗しました。もう一度お試しください。` | トースト |
| 削除しようとした非登録メンバーが既に無い（`404`） | `この非登録メンバーは削除されています。` | トースト（表示後、一覧を取り直す） |
| クリップボードへのコピーに失敗 | `コピーできませんでした。リンクを長押しして手動でコピーしてください。` | トースト |
| 招待コードの再発行に失敗 | `招待コードの再発行に失敗しました。もう一度お試しください。` | トースト |
| 退出に失敗 | `退出に失敗しました。もう一度お試しください。` | トースト |
| グループの削除に失敗 | `家族グループの削除に失敗しました。もう一度お試しください。` | トースト |
| 作成者以外がグループ削除を実行（`403`） | `家族グループを削除できるのは、グループを作成した人だけです。` | トースト |
| 未認証（`401`） | `ログインの有効期限が切れました。もう一度ログインしてください。` | トースト（表示後、ログイン画面へ移動する） |
| グループ未所属（`403`） | `家族グループに参加していません。` | トースト（表示後、家族グループ作成・参加画面へ移動する） |
| 通信できない | `通信に失敗しました。電波状況を確認してもう一度お試しください。` | トースト |

## 8. DBへの影響

### 非登録メンバーの追加・削除

| 操作 | 影響 |
| --- | --- |
| 追加 | `unregistered_members` に1件追加する（`family_id` は自分の所属グループ、`name`、`created_at`） |
| 削除 | `unregistered_members` の該当行を物理削除する。あわせて `todo_assignees` のうちその人を指す行も削除する。その結果、ToDoの担当者が非登録メンバーだけでなくなった場合でも、残ったフォロー役の登録ユーザーはそのまま担当者として残す |

### 招待コードの再発行

| 影響 |
| --- |
| `families` の該当行の `invite_code` を新しい8桁の値に、`invite_code_expires_at` を現在日時の7日後に更新する。古いコードは以後使えなくなる |

### グループの退出

| テーブル | 影響 |
| --- | --- |
| `users` | 自分の行の `family_id` を未設定にする |
| `todo_assignees` | 自分を指す行（`user_id` が自分の行）をすべて削除する。担当者がいなくなったToDoは「担当者なし」として残す |
| `families` | 自分がグループ作成者だった場合、`created_by_user_id` を残ったメンバーのうち最も古くから所属している人（`users.created_at` が最も早い人）に付け替える |
| — | 自分が最後の1人だった場合は、下記「グループの削除」と同じ削除を行う |

### グループの削除

| テーブル | 影響 |
| --- | --- |
| `comments` | そのグループのToDoに紐づく行をすべて削除する |
| `todo_assignees` | そのグループのToDoに紐づく行をすべて削除する |
| `todos` | `family_id` が該当するグループの行をすべて削除する |
| `unregistered_members` | `family_id` が該当するグループの行をすべて削除する |
| `users` | そのグループに所属していた全ユーザーの `family_id` を未設定にする。ユーザーそのものは削除しない |
| `families` | 該当行を削除する |

- `notification_settings`・`push_subscriptions` はユーザーに紐づくデータのため、グループを削除しても消さない。

## 9. 使用API

| API | 用途 |
| --- | --- |
| `GET /families/me` | グループ名・招待コード・有効期限・作成者の取得 |
| `GET /families/me/members` | 登録ユーザー一覧の取得 |
| `GET /families/me/unregistered-members` | 非登録メンバー一覧の取得 |
| `POST /families/me/unregistered-members` | 非登録メンバーの追加 |
| `DELETE /families/me/unregistered-members/:id` | 非登録メンバーの削除 |
| `POST /families/me/invite` | 招待コードの再発行 |
| `POST /families/me/leave` | グループからの退出 |
| `DELETE /families/me` | グループの削除 |
