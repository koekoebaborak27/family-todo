# ToDo詳細画面

共通仕様（用語・権限・API共通規約）は [`00_family-todo共通.md`](00_family-todo共通.md) を参照。

## 1. 画面の目的

1件のToDoの内容をすべて確認し、完了/未完了の切り替え・編集・削除を行う。あわせて、そのToDoに家族が残したコメントを読み書きする。

## 2. 画面へのアクセス条件・初期表示

- ログイン済みかつ家族グループに所属しているユーザーのみが対象。
- ToDo一覧画面でカードをタップして開く。Push通知をタップした場合も直接この画面を開く。
- 画面表示時に `GET /todos/:id` を呼ぶ。応答にはToDo本体・担当者・コメントが含まれる。取得中はローディング表示にする。
- 他のグループのToDoのIDを指定された場合はエラー表示にする（「7. エラー時の表示文言」）。

## 3. 表示項目

### 3.1 ToDo本体

| 項目 | 内容 | 備考 |
| --- | --- | --- |
| 完了状態 | 「未完了」または「完了」 | 完了時は完了者と完了日時も表示する。例: `太郎 が 9/1(月) 20:15 に完了` |
| タイトル | `todos.title` | 全文を折り返して表示する（省略しない） |
| 優先度バッジ | 「高」「中」「低」 | |
| カテゴリバッジ | カテゴリ名 | |
| 期限 | 例: `2026/9/3(水)` 、時刻ありなら `2026/9/3(水) 18:00` | 期限なしのときは `期限なし` |
| 期限超過の印 | 期限を過ぎた未完了のToDoは「期限切れ」と表示する | |
| 繰り返し | `なし` / `毎日` / `毎週 月・木` / `毎月 15日` | |
| 担当者 | 担当者の表示名を並べて表示する | 非登録メンバーは名前の後ろに「(未登録)」、フォロー役の登録ユーザーは名前の後ろに「(通知の受け取り役)」を付ける。担当者なしのときは `担当者なし` |
| 詳細メモ | `todos.memo` | 改行をそのまま表示する。未入力のときは項目ごと表示しない |
| 作成者・作成日時 | 例: `花子 が 8/30(土) に作成` | |

### 3.2 操作ボタン

| ボタン | 表示条件 |
| --- | --- |
| 「完了にする」 | 未完了のとき |
| 「未完了に戻す」 | 完了のとき |
| 「編集」 | 常に表示 |
| 「削除」 | 常に表示 |

### 3.3 コメント

| 項目 | 内容 |
| --- | --- |
| コメント件数 | 例: `コメント (3)` |
| コメント1件ごとの表示 | 投稿者の表示名、投稿日時、本文（改行をそのまま表示）、編集済みの場合は `(編集済み)` |
| 各コメントの操作 | 「編集」「削除」。投稿者本人でなくても表示する |
| 並び順 | 投稿日時が古い順（会話として上から読めるようにするため） |
| 入力欄 | 複数行の入力欄と「送信」ボタン。画面下部に置く |
| コメントが0件のとき | `まだコメントはありません。` |

## 4. 入力チェック

| 項目 | チェック内容 | エラー文言 |
| --- | --- | --- |
| コメント本文 | 未入力（空白のみも含む）でないこと | `コメントを入力してください。` |
| コメント本文 | 500文字以内 | `コメントは500文字以内で入力してください。` |

- 未入力のあいだは「送信」ボタンを操作不可にする。
- コメントの編集も同じチェックを行う。

## 5. 操作と遷移先

| 操作 | 動作 | 遷移先 |
| --- | --- | --- |
| 「完了にする」 | `POST /todos/:id/complete` を呼ぶ。トーストで `完了にしました。` を表示する。繰り返し設定があるToDoは完了にならず期限が次回へ進み、`完了にしました。次回は {次回の期限} です。` を表示する（[`16_ToDo追加・編集.md`](16_ToDo追加・編集.md)） | 同画面（表示を更新する） |
| 「未完了に戻す」 | `POST /todos/:id/incomplete` を呼ぶ。トーストで `未完了に戻しました。` を表示する | 同画面（表示を更新する） |
| 「編集」 | 編集モードで開く | ToDo追加・編集画面 |
| 「削除」 | 確認ダイアログ（`AlertDialog`）で `このToDoを削除します。コメントもすべて消え、元に戻せません。削除しますか？` を表示する。承諾したら `DELETE /todos/:id` を呼び、トーストで `ToDoを削除しました。` を表示する | ToDo一覧画面 |
| コメントの「送信」 | `POST /todos/:id/comments` を呼ぶ。成功したら入力欄を空にし、一覧の末尾に追加する | 同画面 |
| コメントの「編集」 | その行を入力欄に切り替える。「保存」で `PATCH /comments/:id` を呼ぶ。「キャンセル」で元に戻す | 同画面 |
| コメントの「削除」 | 確認ダイアログ（`AlertDialog`）で `このコメントを削除します。元に戻せません。削除しますか？` を表示する。承諾したら `DELETE /comments/:id` を呼ぶ | 同画面 |
| 戻る | | ToDo一覧画面 |

## 6. 権限による差

- 無い。グループのメンバーであれば、誰が作ったToDo・誰が書いたコメントでも、編集・削除・完了操作ができる。
- コメントの「編集」「削除」は投稿者本人以外にも表示する（要件で全メンバーに認めているため）。
- 既読の管理は行わないため、誰が読んだかは表示しない。

## 7. エラー時の表示文言

| 状況 | 表示文言 | 表示場所 |
| --- | --- | --- |
| ToDoが存在しない・他グループのToDo（`404` / `403`） | `このToDoは見つかりませんでした。すでに削除された可能性があります。` | 画面全体（ToDo一覧へ戻るボタンを添える） |
| 取得に失敗（`500` 系） | `ToDoの読み込みに失敗しました。時間をおいてもう一度お試しください。` | 画面全体（再読み込みボタンを添える） |
| 完了/未完了の切り替えに失敗 | `更新に失敗しました。もう一度お試しください。` | トースト |
| 削除に失敗 | `削除に失敗しました。もう一度お試しください。` | トースト |
| 削除しようとしたToDoが既に無い（`404`） | `このToDoは削除されています。` | トースト（表示後、ToDo一覧画面へ移動する） |
| コメントの投稿・編集に失敗 | `コメントの保存に失敗しました。もう一度お試しください。` | トースト（入力内容は残す） |
| コメントの削除に失敗 | `コメントの削除に失敗しました。もう一度お試しください。` | トースト |
| 対象のコメントが既に無い（`404`） | `このコメントは削除されています。` | トースト（表示後、コメント一覧を取り直す） |
| 未認証（`401`）（画面表示・完了/未完了の切り替え・削除） | `ログインの有効期限が切れました。もう一度ログインしてください。` | トースト（表示後、ログイン画面へ移動する） |
| 通信できない（画面表示・完了/未完了の切り替え・削除） | `通信に失敗しました。電波状況を確認してもう一度お試しください。` | トースト |

- コメントの投稿・編集・削除は、401（未認証）・通信エラーを含むすべての失敗を、上記「コメントの投稿・編集に失敗」「コメントの削除に失敗」の文言でまとめて表示する。専用メッセージやログイン画面への遷移は行わない（実装 `apps/frontend/src/modules/todo/ui/todo-detail-screen.tsx` の `handleCreateComment`/`handleUpdateComment`/`handleDeleteComment` に合わせた仕様）。

## 8. DBへの影響

| 操作 | 影響 |
| --- | --- |
| 詳細の表示 | 参照のみ |
| 完了にする | `todos` の該当行を更新する（`status = completed`、`completed_by_user_id` = 自分、`completed_at` = 現在日時、`updated_at` = 現在日時）。繰り返し設定がある場合は `due_at` を次回へ進めるだけにする |
| 未完了に戻す | `todos` の該当行を更新する（`status = incomplete`、`completed_by_user_id`・`completed_at` を未設定に戻す、`updated_at` = 現在日時） |
| ToDoの削除 | `todos` の該当行を物理削除する。あわせて `todo_assignees`・`comments` のうちそのToDoに紐づく行も削除する |
| コメントの投稿 | `comments` に1件追加する（`todo_id`・`user_id` は自分・`body`・`created_at`・`updated_at`） |
| コメントの編集 | `comments` の該当行の `body` と `updated_at` を更新する。`user_id`（投稿者）は書き換えない |
| コメントの削除 | `comments` の該当行を物理削除する |

## 9. 使用API

| API | 用途 |
| --- | --- |
| `GET /todos/:id` | ToDo・担当者・コメントの取得 |
| `POST /todos/:id/complete` | 完了にする |
| `POST /todos/:id/incomplete` | 未完了に戻す |
| `DELETE /todos/:id` | ToDoの削除 |
| `GET /todos/:id/comments` | コメント一覧の取り直し |
| `POST /todos/:id/comments` | コメントの投稿 |
| `PATCH /comments/:id` | コメントの編集 |
| `DELETE /comments/:id` | コメントの削除 |
