# ログイン画面

共通仕様（用語・権限・API共通規約）は [`00_family-todo共通.md`](00_family-todo共通.md) を参照。

## 1. 画面の目的

Googleアカウントでアプリにログインする。ログイン後、そのユーザーが家族グループに所属しているかどうかを判定し、次に表示する画面（ToDo一覧 / 家族グループ作成・参加）を振り分ける。

未ログインのユーザーがアプリのどのURLを開いても、最終的にこの画面へ集約される。

## 2. 画面へのアクセス条件・初期表示

- 未ログイン状態でアプリを開いたときに表示する。
- 保護された画面（ToDo一覧・ToDo詳細など）へ未ログインでアクセスした場合も、この画面へ移動させる。
- すでにログイン済みのユーザーがこの画面を開いた場合は、ログイン画面を表示せず「5. 操作と遷移先」の振り分けに従って自動的に移動する。
- 画面表示時に `GET /auth/me` を呼び、ログイン状態と所属グループの有無を確認する。応答が返るまではローディング表示にする（ログインボタンが一瞬見えてから遷移する、というちらつきを防ぐため）。

## 3. 表示項目

| 項目 | 内容 | 備考 |
| --- | --- | --- |
| アプリ名 | 「家族 de TODO！」 | ロゴ画像またはテキスト |
| キャッチコピー | 「家族のちょっとしたToDoを、みんなで共有。」 | 1行の説明文 |
| Googleでログインボタン | 「Googleでログイン」 | Googleアイコン付き。画面内で唯一の主要操作 |
| ローディング表示 | ログイン処理中はボタンを操作不可にし、「ログインしています…」を表示する | 二重送信を防ぐため |

- 入力欄は無い（アプリ独自のIDやパスワードは持たないため）。

## 4. 入力チェック

ユーザーが値を入力する項目が無いため、この画面での入力チェックは無い。

## 5. 操作と遷移先

| 操作 | 動作 | 遷移先 |
| --- | --- | --- |
| 「Googleでログイン」を押す | Googleの認可画面へ移動する | Google側の画面 |
| Google側で許可した | 認可コードを持ってアプリへ戻り、`POST /auth/google/callback` を呼ぶ。成功したら所属グループの有無で振り分ける | 下記のとおり |
| Google側で拒否した / 中断した | ログイン画面に戻り、エラーメッセージを表示する | ログイン画面（そのまま） |

ログイン成功後の振り分け:

- 所属グループが**ある**（`users.family_id` が設定されている）→ **ToDo一覧画面**
- 所属グループが**ない**（`users.family_id` が未設定）→ **家族グループ作成・参加画面**

補足:

- 招待リンク経由で未ログインのままアクセスした場合は、ログイン後に招待コードを引き継いだ状態で家族グループ作成・参加画面へ移動する（詳細は [`12_家族グループ作成・参加.md`](12_家族グループ作成・参加.md)）。
- 初回ログイン（`users` を新規作成したログイン）の直後、遷移先の画面でブラウザのPush通知許可リクエストを表示する。ログイン画面では表示しない。
- iOS Safariかつホーム画面未インストールの場合、遷移先の画面にインストール案内を重ねて表示する（[`24_iOSインストール案内.md`](24_iOSインストール案内.md)）。

## 6. 権限による差

無い。未ログインのユーザー全員に同じ画面を表示する。

## 7. エラー時の表示文言

いずれもログイン画面上に表示する（トーストではなく、ボタンの下に固定表示する。原因を読んでから再操作してほしいため）。

| 状況 | 表示文言 |
| --- | --- |
| Google側でログインを拒否・中断した | `Googleログインがキャンセルされました。もう一度お試しください。` |
| 認可コードが不正・期限切れ（`POST /auth/google/callback` が `400`） | `ログインに失敗しました。もう一度お試しください。` |
| サーバーエラー（`500` 系） | `サーバーでエラーが発生しました。時間をおいてもう一度お試しください。` |
| 通信できない（ネットワーク断・タイムアウト） | `通信に失敗しました。電波状況を確認してもう一度お試しください。` |

## 8. DBへの影響

| タイミング | 影響 |
| --- | --- |
| 初回ログイン時 | `users` に1件追加する（`google_sub`・`email`・`display_name`・`created_at`。`display_name` の初期値はGoogleアカウントの氏名、`family_id` は未設定） |
| 初回ログイン時 | `notification_settings` に、そのユーザーの4種別（`todo_added` / `assignee_set` / `due_soon` / `overdue`）を既定値で追加する。すべて `enabled = true`、`due_soon` は `remind_before_value = 1` / `remind_before_unit = days` |
| 2回目以降のログイン時 | `users` への追加・更新は行わない（既存行を `google_sub` で特定するのみ） |

Push通知の購読情報（`push_subscriptions`）は、遷移先の画面でブラウザの許可を得た後に登録する。この画面では登録しない。

## 9. 使用API

| API | 用途 |
| --- | --- |
| `GET /auth/me` | 画面表示時にログイン状態と所属グループの有無を確認する |
| `POST /auth/google/callback` | Googleから戻った認可コードでログインセッションを発行する |
