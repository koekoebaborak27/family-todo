# 家族グループ作成・参加画面

共通仕様（用語・権限・API共通規約）は [`00_family-todo共通.md`](00_family-todo共通.md) を参照。

## 1. 画面の目的

まだどの家族グループにも所属していないユーザーが、家族グループを新しく作るか、家族から共有された招待コード（招待リンク）で既存のグループに参加する。

ToDo一覧はグループへの所属を前提にしているため、未所属のユーザーはこの画面を通らないと先へ進めない。

## 2. 画面へのアクセス条件・初期表示

- ログイン済みかつ**グループ未所属**のユーザーのみが対象。
- ログイン直後に所属グループが無い場合、この画面へ強制的に移動する。
- グループから退出した直後、または所属していたグループが削除された直後もこの画面へ戻る。
- すでにグループへ所属しているユーザーがこの画面を開いた場合は、ToDo一覧画面へ移動させる（二重所属を防ぐため）。
- 招待リンク（`/join?code=XXXXXXXX`）から来た場合は、「招待コードで参加する」側を最初から開いた状態にし、コード入力欄にリンクのコードを埋めておく。未ログインでリンクを開いた場合は、ログイン画面を経由してからこの状態にする。

## 3. 表示項目

「家族グループを作る」「招待コードで参加する」の2つをタブで切り替える。既定は「家族グループを作る」。招待リンク経由のときだけ「招待コードで参加する」を既定にする。

### 共通

| 項目 | 内容 |
| --- | --- |
| 画面タイトル | 「家族グループ」 |
| 説明文 | 「ToDoを共有する家族グループを作るか、家族から届いた招待コードで参加してください。」 |

### タブ1: 家族グループを作る

| 項目 | 内容 | 備考 |
| --- | --- | --- |
| グループ名 | 入力欄（1行） | プレースホルダー「例: 山田家」 |
| 作成ボタン | 「この名前で作成する」 | |

### タブ2: 招待コードで参加する

| 項目 | 内容 | 備考 |
| --- | --- | --- |
| 招待コード | 入力欄（1行） | プレースホルダー「例: A3F9K2QP」。入力された英字は自動で大文字に直す |
| 参加ボタン | 「参加する」 | |

## 4. 入力チェック

| 項目 | チェック内容 | エラー文言 |
| --- | --- | --- |
| グループ名 | 未入力でないこと | `グループ名を入力してください。` |
| グループ名 | 30文字以内 | `グループ名は30文字以内で入力してください。` |
| 招待コード | 未入力でないこと | `招待コードを入力してください。` |
| 招待コード | 半角英数字8桁であること | `招待コードは半角英数字8桁で入力してください。` |

- チェックはボタンを押したときに行い、該当する入力欄の下にエラー文言を表示する。
- 送信中はボタンを操作不可にする（同じグループが2つ作られるのを防ぐため）。

## 5. 操作と遷移先

| 操作 | 動作 | 遷移先 |
| --- | --- | --- |
| 「この名前で作成する」を押す | `POST /families` を呼ぶ。成功すると自分がそのグループの作成者かつ最初のメンバーになる | ToDo一覧画面 |
| 「参加する」を押す | `POST /families/join` を呼ぶ。成功するとそのグループのメンバーになる | ToDo一覧画面 |
| タブを切り替える | 表示を切り替えるだけ。入力済みの値とエラー表示は消す | 同画面 |

- 移動先のToDo一覧画面で、作成時は `家族グループ「山田家」を作成しました。` 、参加時は `家族グループ「山田家」に参加しました。` をトーストで表示する（`{グループ名}` の部分は実際の名前に置き換える）。
- 初回ログイン直後にこの画面へ来た場合は、画面表示のタイミングでブラウザのPush通知許可リクエストを表示する。
- iOS Safariかつホーム画面未インストールの場合、この画面にインストール案内を重ねて表示する（[`24_iOSインストール案内.md`](24_iOSインストール案内.md)）。

## 6. 権限による差

- 無い。グループ未所属のユーザーは全員、作成も参加も行える。
- 作成した本人が `families.created_by_user_id` に記録され、以後そのグループを削除できる唯一のメンバーになる（[`20_家族グループ設定.md`](20_家族グループ設定.md)）。

## 7. エラー時の表示文言

| 状況 | 表示文言 | 表示場所 |
| --- | --- | --- |
| 招待コードに一致するグループが無い（`404`） | `招待コードが正しくありません。家族に確認してください。` | 招待コード入力欄の下 |
| 招待コードの有効期限が切れている（`400`） | `この招待コードは有効期限が切れています。家族に招待リンクを再発行してもらってください。` | 招待コード入力欄の下 |
| すでにどこかのグループに所属している（`409`） | `すでに家族グループに参加しています。` | 画面上部（この後ToDo一覧へ移動する） |
| 未認証（`401`） | `ログインの有効期限が切れました。もう一度ログインしてください。` | 画面上部（この後ログイン画面へ移動する） |
| サーバーエラー（`500` 系） | `サーバーでエラーが発生しました。時間をおいてもう一度お試しください。` | 画面上部 |
| 通信できない（ネットワーク断・タイムアウト） | `通信に失敗しました。電波状況を確認してもう一度お試しください。` | 画面上部 |

## 8. DBへの影響

### グループを作成したとき

| テーブル | 影響 |
| --- | --- |
| `families` | 1件追加する。`name` は入力値、`created_by_user_id` は自分、`invite_code` は自動生成した半角英数字8桁（大文字。同じコードが既に使われていない値）、`invite_code_expires_at` は作成日時の7日後、`created_at` は現在日時 |
| `users` | 自分の行の `family_id` を作成したグループのIDに更新する |

### 招待コードで参加したとき

| テーブル | 影響 |
| --- | --- |
| `users` | 自分の行の `family_id` を参加したグループのIDに更新する |
| `families` | 変更しない（招待コードは参加しても失効させない。家族の残りのメンバーが同じコードで参加できるようにするため） |

## 9. 使用API

| API | 用途 |
| --- | --- |
| `GET /auth/me` | 画面表示時に、すでにグループへ所属していないかを確認する |
| `POST /families` | 家族グループを新規作成する |
| `POST /families/join` | 招待コードでグループに参加する |
