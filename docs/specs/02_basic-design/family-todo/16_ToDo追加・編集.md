# ToDo追加・編集画面

共通仕様（用語・権限・API共通規約）は [`00_family-todo共通.md`](00_family-todo共通.md) を参照。

## 1. 画面の目的

ToDoを新しく作る、または既存のToDoの内容を書き換える。新規作成と編集で入力項目・入力チェックが同じため、1つの画面で兼用する。

## 2. 画面へのアクセス条件・初期表示

- ログイン済みかつ家族グループに所属しているユーザーのみが対象。
- 2つのモードがある。

| モード | 入口 | 画面タイトル | 保存ボタンの文言 |
| --- | --- | --- | --- |
| 新規作成 | ToDo一覧画面の右下の追加ボタン | 「ToDoを追加」 | 「追加する」 |
| 編集 | ToDo詳細画面の「編集」ボタン | 「ToDoを編集」 | 「保存する」 |

- 新規作成のときの初期値は次のとおり。タイトル・詳細メモは空、カテゴリは「その他」、優先度は「中」、期限はなし、担当者はなし、繰り返しは「なし」。
- 編集のときは `GET /todos/:id` で取得した値を各項目に入れておく。取得中はローディング表示にする。
- 画面表示時に `GET /categories`・`GET /families/me/members`・`GET /families/me/unregistered-members` を呼び、選択肢を用意する。

## 3. 表示項目

| 項目 | 入力方法 | 必須 | 備考 |
| --- | --- | --- | --- |
| タイトル | 1行の入力欄 | 必須 | プレースホルダー「例: 牛乳を買う」 |
| 詳細メモ | 複数行の入力欄 | 任意 | |
| カテゴリ | 選択（`Select`） | 必須 | 学校 / 仕事 / 習い事 / 家事 / 買い物 / その他の6件 |
| 優先度 | 3つから1つ選ぶボタン | 必須 | 高 / 中 / 低 |
| 期限 | 「期限を設定する」のON/OFF＋日付選択＋「時刻も指定する」のON/OFF＋時刻選択 | 任意 | 「期限を設定する」がOFFのときは日付・時刻を表示しない |
| 担当者 | 一覧から複数選ぶ | 任意 | 下記「3.1 担当者の選び方」 |
| 繰り返し | 選択（なし / 毎日 / 毎週 / 毎月） | 必須 | 「毎週」「毎月」を選んだときだけ追加の指定欄を表示する |
| 繰り返しの曜日 | 曜日を複数選ぶ（日〜土） | 「毎週」のとき必須 | |
| 繰り返しの日付 | 1〜31から1つ選ぶ | 「毎月」のとき必須 | |
| 保存ボタン | | | 送信中は操作不可にする |
| キャンセル | 押すと入力を破棄して前の画面に戻る | | |

### 3.1 担当者の選び方

- 「家族（登録ユーザー）」と「非登録メンバー」を分けて一覧表示し、それぞれチェックで選ぶ。
- 非登録メンバーの名前の後ろには「(未登録)」を付けて、ログインしない担当者であることが分かるようにする。
- 非登録メンバーを1人でも選ぶと、その下に「フォロー役」を選ぶ欄が現れる。フォロー役は登録ユーザーの中から1人以上選ぶ（この人に通知が届く）。
- フォロー役の欄には次の説明文を添える: `ログインしないメンバーの代わりに通知を受け取る家族を選んでください。`
- 非登録メンバーの選択をすべて外すと、フォロー役の欄と選択内容は消える。
- 非登録メンバーがまだ1人も登録されていない場合は、その一覧の位置に `非登録メンバーは登録されていません。家族グループ設定から追加できます。` と表示する。

## 4. 入力チェック

| 項目 | チェック内容 | エラー文言 |
| --- | --- | --- |
| タイトル | 未入力（空白のみも含む）でないこと | `タイトルを入力してください。` |
| タイトル | 100文字以内 | `タイトルは100文字以内で入力してください。` |
| 詳細メモ | 1000文字以内 | `詳細メモは1000文字以内で入力してください。` |
| カテゴリ | 選択されていること | `カテゴリを選択してください。` |
| 優先度 | 選択されていること | `優先度を選択してください。` |
| 期限（日付） | 「期限を設定する」がONのとき、日付が入力されていること | `期限の日付を選択してください。` |
| 期限（時刻） | 「時刻も指定する」がONのとき、時刻が入力されていること | `期限の時刻を選択してください。` |
| 担当者（フォロー役） | 非登録メンバーを担当者に含めるとき、フォロー役の登録ユーザーが1人以上選ばれていること | `ログインしないメンバーを担当者にする場合は、通知を受け取る家族を1人以上選んでください。` |
| 繰り返し（毎週） | 曜日が1つ以上選ばれていること | `繰り返す曜日を選択してください。` |
| 繰り返し（毎月） | 日付が選ばれていること | `繰り返す日付を選択してください。` |
| 繰り返しと期限 | 繰り返しが「なし」以外のとき、期限が設定されていること | `繰り返しを設定する場合は期限も設定してください。` |

- チェックは保存ボタンを押したときに行い、該当する項目の下にエラー文言を表示する。エラーがある項目のうち一番上のものへ画面を送る。
- 過去の日付を期限に指定することは許可する（「本当は昨日までだった」用事を後から登録できるようにするため）。

## 5. 操作と遷移先

| 操作 | 動作 | 遷移先 |
| --- | --- | --- |
| 「追加する」を押す（新規作成） | `POST /todos` を呼ぶ。成功したらトーストで `ToDoを追加しました。` を表示する | ToDo一覧画面 |
| 「保存する」を押す（編集） | `PATCH /todos/:id` と `PUT /todos/:id/assignees` を呼ぶ。成功したらトーストで `ToDoを保存しました。` を表示する | ToDo詳細画面 |
| 「キャンセル」または戻るを押す | 入力に変更がある場合は確認ダイアログ（`AlertDialog`）で `入力中の内容は保存されません。編集をやめますか？` を表示し、承諾したら破棄する。変更が無ければそのまま戻る | 新規作成ならToDo一覧画面、編集ならToDo詳細画面 |

- 担当者は `PUT /todos/:id/assignees` で丸ごと置き換える（追加・削除を個別に送らない）。

## 6. 権限による差

無い。グループのメンバーであれば、誰が作ったToDoでも編集できる。作成者だけが編集できるといった制限は設けない。

## 7. エラー時の表示文言

| 状況 | 表示文言 | 表示場所 |
| --- | --- | --- |
| 入力エラー（`400`） | 該当項目があれば「4. 入力チェック」の文言を項目の下に表示する。特定できない場合は `入力内容に誤りがあります。内容を確認してください。` | 項目の下、または画面上部 |
| フォロー役が不足（`400`） | `ログインしないメンバーを担当者にする場合は、通知を受け取る家族を1人以上選んでください。` | 担当者欄の下 |
| 編集対象が既に削除されている（`404`） | `このToDoは削除されています。` | トースト（表示後、ToDo一覧画面へ移動する） |
| 未認証（`401`） | `ログインの有効期限が切れました。もう一度ログインしてください。` | トースト（表示後、ログイン画面へ移動する） |
| グループ未所属（`403`） | `家族グループに参加していません。` | トースト（表示後、家族グループ作成・参加画面へ移動する） |
| サーバーエラー（`500` 系） | `保存に失敗しました。時間をおいてもう一度お試しください。` | 画面上部 |
| 通信できない | `通信に失敗しました。電波状況を確認してもう一度お試しください。` | 画面上部 |

- 保存に失敗した場合、入力した内容は消さずに画面へ残す。

## 8. DBへの影響

### 新規作成したとき

| テーブル | 影響 |
| --- | --- |
| `todos` | 1件追加する。`family_id` は自分の所属グループ、`status` は `incomplete`、`created_by_user_id` は自分、`completed_by_user_id`・`completed_at` は未設定、`created_at`・`updated_at` は現在日時 |
| `todo_assignees` | 選ばれた担当者の数だけ追加する。登録ユーザーは `user_id`、非登録メンバーは `unregistered_member_id` に入れる。フォロー役として選ばれた登録ユーザーは `is_follower = true` で追加する |

### 編集したとき

| テーブル | 影響 |
| --- | --- |
| `todos` | 該当行を更新する。`updated_at` を現在日時にする。`status`・`completed_by_user_id`・`completed_at`・`created_by_user_id` は変更しない |
| `todo_assignees` | 該当ToDoの行をすべて削除し、選び直された担当者で入れ直す |

### 繰り返しの保存形式

| 繰り返し | `recurrence_type` | `recurrence_config` |
| --- | --- | --- |
| なし | `none` | 未設定 |
| 毎日 | `daily` | 未設定 |
| 毎週 | `weekly` | 選ばれた曜日の一覧。日曜=0〜土曜=6。例: `{"weekdays":[1,4]}` |
| 毎月 | `monthly` | 選ばれた日付。例: `{"day":15}` |

### 繰り返しToDoを完了にしたときの動き

繰り返し設定のあるToDoは、完了にしても完了タブへは移らない。同じToDoの期限を次回へ進め、未完了のまま一覧に残す。

| テーブル | 影響 |
| --- | --- |
| `todos` | `due_at` を次回の期限に更新し、`updated_at` を現在日時にする。`status` は `incomplete` のまま、`completed_by_user_id`・`completed_at` は未設定のままにする（誰がいつ済ませたかは記録しない） |

次回の期限の求め方（`due_has_time` が `true` のときは時刻を保ったまま日付だけを進める）:

| 繰り返し | 次回の期限 |
| --- | --- |
| 毎日 | 今の期限の翌日 |
| 毎週 | 選ばれた曜日のうち、今の期限より後で最も近い日 |
| 毎月 | 選ばれた日付の翌月分。その月に該当する日が無いとき（例: 31日で2月）はその月の末日 |

- 完了操作の直後、一覧では `完了にしました。次回は {次回の期限} です。` をトーストで表示する（`{次回の期限}` は `9/4(木)` の形式）。

## 9. 使用API

| API | 用途 |
| --- | --- |
| `GET /categories` | カテゴリの選択肢の取得 |
| `GET /families/me/members` | 担当者に選べる登録ユーザーの取得 |
| `GET /families/me/unregistered-members` | 担当者に選べる非登録メンバーの取得 |
| `GET /todos/:id` | 編集モードでの既存値の取得 |
| `POST /todos` | 新規作成 |
| `PATCH /todos/:id` | 編集の保存 |
| `PUT /todos/:id/assignees` | 担当者の置き換え |
