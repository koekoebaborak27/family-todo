# ToDo一覧画面

共通仕様（用語・権限・API共通規約）は [`00_family-todo共通.md`](00_family-todo共通.md) を参照。

## 1. 画面の目的

家族グループで共有しているToDoを一覧で確認する。ログイン後のホーム画面であり、ToDoの追加・完了・詳細表示への入口を兼ねる。

## 2. 画面へのアクセス条件・初期表示

- ログイン済みかつ家族グループに所属しているユーザーのみが対象。
- 未ログインならログイン画面へ、グループ未所属なら家族グループ作成・参加画面へ移動させる。
- 初期表示は「未完了」タブ・「期限順」タブ・カテゴリ絞り込み「すべて」。
- 初回ログイン直後にこの画面へ来た場合は、画面表示のタイミングでブラウザのPush通知許可リクエストを表示する。許可されたら購読情報を `POST /push-subscriptions` で登録する。
- iOS Safariかつホーム画面未インストールの場合、この画面にインストール案内を重ねて表示する（[`24_iOSインストール案内.md`](24_iOSインストール案内.md)）。

## 3. 表示項目

### 3.1 画面の構成

上から順に次のように並べる。

1. ヘッダー（グループ名・メニュー）
2. 完了状態タブ（未完了 / 完了）
3. 並び順タブ（期限順 / 優先度順）
4. 並び替えプルダウン2つ（並び替える項目 / 昇順・降順）
5. カテゴリ絞り込みチップ
6. ToDoカードの一覧
7. ToDo追加ボタン（画面右下に固定）

### 3.2 ヘッダー

| 項目 | 内容 |
| --- | --- |
| グループ名 | 所属している家族グループの名前 |
| メニューボタン | 押すと「家族グループ設定」「個人設定」「ログアウト」を選べる |

### 3.3 完了状態タブ

| タブ | 内容 |
| --- | --- |
| 未完了 | `status = incomplete` のToDo。既定で選択される |
| 完了 | `status = completed` のToDo |

- 件数が多くなる想定が無いため（家族数名の利用）、どちらのタブも該当するToDoを全件表示する。ページ送り・無限スクロールはMVPでは設けない。

### 3.4 並び順タブと並び替えプルダウン

並び順タブは「その並び順で表示を始める」ためのもので、タブを選ぶと並び替えプルダウンの値がそのタブの初期値に戻る。プルダウンを操作した後は、タブの並び順とは関係なくプルダウンの指定が優先される。

| 並び順タブ | プルダウンの初期値 |
| --- | --- |
| 期限順（既定） | 並び替える項目「期限」／並び順「昇順」 |
| 優先度順 | 並び替える項目「優先度」／並び順「降順」 |

| プルダウン | 選択肢 |
| --- | --- |
| 並び替える項目 | 期限 / 優先度 / 担当者 |
| 並び順 | 昇順 / 降順 |

並び替えの規則:

| 項目 | 昇順の意味 | 降順の意味 | 値が無いToDoの扱い |
| --- | --- | --- | --- |
| 期限 | 期限が早い順 | 期限が遅い順 | 期限なしは昇順・降順のどちらでも末尾にまとめる |
| 優先度 | 低 → 中 → 高 | 高 → 中 → 低 | 優先度は必須のため該当なし |
| 担当者 | 担当者の表示名の五十音順 | 表示名の五十音順の逆 | 担当者なしは昇順・降順のどちらでも末尾にまとめる |

- 担当者が複数いるToDoは、表示名を五十音順に並べたときの先頭の名前で比較する。
- 並び替えた結果が同じ値になったToDo同士は、作成日時が新しい順に並べる（並び順が毎回変わって見えるのを防ぐため）。
- 並び替えは取得済みのToDoに対して画面側で行う。家族数名分の件数しか扱わないため、並び順ごとにAPIを呼び直さない。

### 3.5 カテゴリ絞り込みチップ

- 「すべて」＋固定カテゴリ6件（学校 / 仕事 / 習い事 / 家事 / 買い物 / その他）を横一列に並べ、1つだけ選べる。既定は「すべて」。
- 選択を変えると `GET /todos` を `category_id` 付きで呼び直す。

### 3.6 ToDoカード

| 項目 | 内容 | 備考 |
| --- | --- | --- |
| 完了チェックボックス | 押すと完了/未完了を切り替える | カード左端 |
| タイトル | `todos.title` | 長い場合は2行まで表示し、以降は省略する |
| 優先度バッジ | 「高」「中」「低」 | 色だけでなく文字でも示す |
| カテゴリバッジ | カテゴリ名 | |
| 期限 | 例: `9/3(水)` 、時刻ありなら `9/3(水) 18:00` | 期限なしのときは表示しない |
| 期限超過の印 | 期限を過ぎた未完了のToDoは期限を強調表示し、「期限切れ」と文字でも示す | 未完了タブのみ |
| 繰り返しの印 | 繰り返し設定があるとき、繰り返しアイコンと「毎日」「毎週」「毎月」を表示する | |
| 担当者 | 担当者の表示名を並べて表示する | 非登録メンバーは名前の後ろに「(未登録)」を付ける。担当者なしのときは「担当者なし」 |
| コメント件数 | コメントがある場合のみ、アイコンと件数を表示する | |
| 完了者・完了日時 | 完了タブのみ表示する。例: `太郎 が 9/1(月) に完了` | |

### 3.7 該当するToDoが0件のとき

| 状況 | 表示文言 |
| --- | --- |
| 未完了タブ・絞り込みなしで0件 | `未完了のToDoはありません。右下のボタンから追加できます。` |
| 完了タブ・絞り込みなしで0件 | `完了したToDoはまだありません。` |
| カテゴリで絞り込んだ結果0件 | `このカテゴリのToDoはありません。` |

## 4. 入力チェック

この画面に文字を入力する項目は無いため、入力チェックは無い。タブ・プルダウン・チップはいずれも決められた選択肢からの選択のみを受け付ける。

## 5. 操作と遷移先

| 操作 | 動作 | 遷移先 |
| --- | --- | --- |
| ToDoカードをタップ | そのToDoの詳細を開く | ToDo詳細画面 |
| 完了チェックボックスを押す（未完了→完了） | `POST /todos/:id/complete` を呼ぶ。成功したらそのカードを一覧から消し、トーストで `完了にしました。` と「元に戻す」を表示する | 同画面 |
| 完了チェックボックスを押す（完了→未完了） | `POST /todos/:id/incomplete` を呼ぶ。成功したらトーストで `未完了に戻しました。` を表示する | 同画面 |
| トーストの「元に戻す」を押す | 直前の完了操作を取り消す（`POST /todos/:id/incomplete`） | 同画面 |
| 右下の追加ボタンを押す | 新規作成モードで開く | ToDo追加・編集画面 |
| 完了状態タブを切り替える | `GET /todos` を `status` を変えて呼び直す。並び順タブとプルダウンの状態は引き継ぐ | 同画面 |
| 並び順タブを切り替える | プルダウンをそのタブの初期値に戻し、並べ替える。APIは呼び直さない | 同画面 |
| 並び替えプルダウンを変える | その指定で並べ替える。APIは呼び直さない | 同画面 |
| カテゴリチップを選ぶ | `GET /todos` を `category_id` を変えて呼び直す | 同画面 |
| メニュー →「家族グループ設定」 | | 家族グループ設定画面 |
| メニュー →「個人設定」 | | 個人設定画面 |
| メニュー →「ログアウト」 | 確認ダイアログ（`AlertDialog`）で `ログアウトします。よろしいですか？` を表示し、承諾したら `POST /auth/logout` を呼ぶ | ログイン画面 |
| 一覧を下に引っ張る（プルダウン更新） | `GET /todos` を今の条件で呼び直す | 同画面 |

- 完了・未完了の切り替えは、応答を待たずに先に画面上の表示を切り替える。失敗した場合は表示を元に戻し、エラー文言をトーストで表示する（タップしてから反応するまでの待ち時間をなくすため）。

## 6. 権限による差

- 無い。グループのメンバーであれば、誰のToDoでも閲覧・完了/未完了の切り替え・編集・削除ができる。
- 自分が担当者かどうかによる表示や操作の制限も設けない（担当者の違いは通知の宛先にのみ影響する）。

## 7. エラー時の表示文言

| 状況 | 表示文言 | 表示場所 |
| --- | --- | --- |
| 一覧の取得に失敗（`500` 系） | `ToDoの読み込みに失敗しました。時間をおいてもう一度お試しください。` | 一覧の位置に再読み込みボタンと共に表示 |
| 一覧の取得に失敗（通信できない） | `通信に失敗しました。電波状況を確認してもう一度お試しください。` | 一覧の位置に再読み込みボタンと共に表示 |
| 完了/未完了の切り替えに失敗 | `更新に失敗しました。もう一度お試しください。` | トースト |
| 対象のToDoが既に削除されている（`404`） | `このToDoは削除されています。` | トースト（表示後、一覧を再取得する） |
| 未認証（`401`） | `ログインの有効期限が切れました。もう一度ログインしてください。` | トースト（表示後、ログイン画面へ移動する） |
| グループ未所属（`403`） | `家族グループに参加していません。` | トースト（表示後、家族グループ作成・参加画面へ移動する） |

## 8. DBへの影響

| 操作 | 影響 |
| --- | --- |
| 一覧の表示・並び替え・絞り込み | 参照のみ。更新は行わない |
| 完了にする | `todos` の該当行を更新する。`status = completed`、`completed_by_user_id` = 自分、`completed_at` = 現在日時、`updated_at` = 現在日時 |
| 未完了に戻す | `todos` の該当行を更新する。`status = incomplete`、`completed_by_user_id` = 未設定、`completed_at` = 未設定、`updated_at` = 現在日時 |
| Push通知の許可 | 許可された場合、`push_subscriptions` に1件追加する（同じ `endpoint` が既にあれば追加しない） |

- 繰り返し設定を持つToDoを完了にしたときの次回分の扱い（新しいToDoを自動で作るか、期限を進めるか）は [`16_ToDo追加・編集.md`](16_ToDo追加・編集.md) で定める。

## 9. 使用API

| API | 用途 |
| --- | --- |
| `GET /auth/me` | ログイン状態とグループ所属の確認 |
| `GET /families/me` | ヘッダーに表示するグループ名の取得 |
| `GET /categories` | カテゴリ絞り込みチップの選択肢の取得 |
| `GET /todos` | ToDo一覧の取得（`status`・`category_id`） |
| `POST /todos/:id/complete` | 完了にする |
| `POST /todos/:id/incomplete` | 未完了に戻す |
| `POST /push-subscriptions` | Push通知の購読情報の登録 |
| `POST /auth/logout` | ログアウト |
