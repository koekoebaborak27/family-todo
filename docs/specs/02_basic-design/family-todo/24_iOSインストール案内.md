# iOSインストール案内

共通仕様（用語・権限・API共通規約）は [`00_family-todo共通.md`](00_family-todo共通.md) を参照。

## 1. 画面の目的

iOSのSafariでこのアプリを開いていて、まだホーム画面に追加（インストール）していないユーザーに、追加のしかたを案内する。

iOSではホーム画面に追加していないとWeb Push通知を受け取れないため（要件定義書「16. 技術的制約」）、通知を使ってもらうには追加してもらう必要がある。

これは独立したページではなく、他の画面の上に重ねて表示するバナーとモーダルの組み合わせである。

## 2. 表示条件

次の条件を**すべて**満たすときに表示する。

1. iOS（iPhone / iPad）のSafariで開いている。
2. ホーム画面に追加した状態で開いていない（`display-mode: standalone` ではない）。
3. 「閉じる」を押してから7日が経過している、または一度も閉じていない。

表示する画面:

| 画面 | 表示 |
| --- | --- |
| ToDo一覧画面 | する |
| 家族グループ作成・参加画面 | する |
| 上記以外の画面（ログイン・ToDo追加編集・ToDo詳細・各設定） | しない |

- 所属グループの有無によらず、同じ条件で表示する。
- 個人設定画面の「追加のしかたを見る」ボタンからは、上記の表示条件にかかわらず手順モーダルを直接開ける（[`22_個人設定.md`](22_個人設定.md)）。

## 3. 表示項目

### 3.1 バナー（常設）

画面の上部、ヘッダーのすぐ下に細いバナーとして常に表示する。下の内容が画面の操作を邪魔しないよう、バナーの高さの分だけ本文を下げる。

| 項目 | 内容 |
| --- | --- |
| アイコン | ホーム画面への追加を表すアイコン |
| 本文 | `ホーム画面に追加すると、通知を受け取れます。` |
| 「追加のしかた」ボタン | 押すと手順モーダルを開く |
| 「×」ボタン | 押すとバナーを閉じる（`aria-label` は `閉じる`） |

### 3.2 手順モーダル

`Drawer`（下からスライドする形）で表示する。モバイル中心の画面であるため、`Dialog` ではなく `Drawer` を使う。

| 項目 | 内容 |
| --- | --- |
| 見出し | `ホーム画面に追加する` |
| 説明文 | `iPhone・iPadでは、ホーム画面に追加したときだけ通知を受け取れます。次の手順で追加してください。` |
| 手順1 | `画面の下にある「共有」ボタン（□に↑のアイコン）を押します。` |
| 手順2 | `メニューを下にスクロールして「ホーム画面に追加」を押します。` |
| 手順3 | `右上の「追加」を押します。` |
| 補足 | `追加した後は、ホーム画面のアイコンからアプリを開いてください。` |
| 「閉じる」ボタン | モーダルを閉じてバナーの表示に戻る |

- 手順の中で「共有」「ホーム画面に追加」「追加」といったiOS側のボタン名は、実機の表示と同じ言葉をそのまま書く。

## 4. 入力チェック

ユーザーが値を入力する項目が無いため、入力チェックは無い。

## 5. 操作と遷移先

| 操作 | 動作 | 遷移先 |
| --- | --- | --- |
| バナーの「追加のしかた」を押す | 手順モーダルを開く | 同画面（モーダルを重ねる） |
| バナーの「×」を押す | バナーを閉じ、閉じた日時を端末に記録する。以後7日間はバナーを表示しない | 同画面（バナーが消える） |
| モーダルの「閉じる」を押す、またはモーダルの外側を押す | モーダルを閉じる。バナーは表示したままにする（閉じたことにはしない） | 同画面 |
| ホーム画面に追加してアプリを開き直す | 表示条件2を満たさなくなるため、バナーは表示しない | — |

- ページを移動しても、表示条件を満たす画面ではバナーを表示し続ける（アプリを開いている間だけ消える一時的な非表示にはしない）。

## 6. 権限による差

無い。グループへの所属や、グループ内での役割による違いは無い。使っている端末とブラウザの種類だけで表示を判断する。

## 7. エラー時の表示文言

- サーバーへの通信を行わないため、この案内に固有のエラーは無い。
- 閉じた日時を端末に保存できなかった場合（プライベートブラウズ等で保存が使えない場合）もエラーは表示しない。次にアプリを開いたときにバナーが再び出るだけとして扱う。

## 8. DBへの影響

無い。「×」で閉じたときの日時は端末側（ブラウザの保存領域）にのみ記録し、サーバーへは送らない。端末ごとに事情が違うため、アカウント単位で覚える必要が無いためである。

## 9. 使用API

無い。
