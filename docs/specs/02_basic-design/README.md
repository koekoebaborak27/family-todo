# 02_basic-design/ — 基本設計書

機能ごとにディレクトリを作り、画面・処理の単位でファイルを分ける。

```
02_basic-design/
├─ <機能名>/
│  ├─ README.md        ← この機能の索引
│  ├─ 00_<機能名>共通.md ← 用語・共通仕様・権限
│  ├─ 01_データベース.md ← この機能が使うテーブル
│  ├─ 02_API仕様.md     ← REST APIエンドポイント一覧
│  ├─ 10_<画面名>.md
│  └─ 11_<画面名>.md
└─ 画面遷移図.md         ← 全体の画面遷移（.mmd + .svg。docs/diagrams.md 参照）
```

各画面のファイルに書くこと: 画面の目的、表示項目、入力チェック、操作と遷移先、権限による差、エラー時の表示文言、DB への影響。

**エラーメッセージなどの文言は実際に表示する文字列をそのまま書く。** 単体テスト仕様書（`docs/test/unit/spec/`）がここから転記するため。
